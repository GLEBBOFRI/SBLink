# 🤖 SBLink (v1.0 Stable)

> **SBLink** — умный, дерзкий и минималистичный Telegram-бот для быстрого сохранения и поиска учебных ссылок по предметам. Работает на Google Apps Script и использует Google Таблицы в качестве базы данных.

![SBLink Avatar](https://github.com/GLEBBOFRI/SBLink/blob/ff1fb812219385fbcbf8b5702bc9703789076cd3/ava_preview.jpg)

---

## 🔥 Особенности

- ⚡ **Полная интеграция с Google Таблицами:** Все ссылки сохраняются в единой Google Sheet в реальном времени.
- 🔒 **Строгая авторизация:** Доступ только для разрешенного Telegram ID (незваные гости сразу отправляются по известному адресу).
- 🗑 **Двухэтапное безопасное удаление:** Удобное интерактивное меню с подтверждением перед сносом записи, чтобы случайно ничего не стереть на паре.
- 🎭 **Собственный характер:** Бот не скучный робот — у него есть чувство юмора и встроенные системы защиты от несанкционированного ввода.

---

## 🛠 Технологии

- **Язык:** JavaScript / Google Apps Script (GAS)
- **База данных:** Google Sheets API
- **Платформа:** Telegram Bot API (Webhook)

## 🚀 Установка и настройка

1. **Создай Google Таблицу:**
   - Создай пустую Гугл Таблицу на своем Google Диске.

2. **Создай Telegram Бота:**
   - Напиши [@BotFather](https://t.me/BotFather) в Telegram и создай нового бота, получи его **API Token**.

3. **Разверни Apps Script:**
   - В Google Таблице перейди в `Расширения` -> `Apps Script`.
   - Вставь код из файла `Code.gs`.
   - Замени значения констант в начале файла:
     ```javascript
     const TOKEN = "ТВОЙ_ТОКЕН_БОТА";
     const ALLOWED_TELEGRAM_ID = 123456789; // Твой Telegram ID
     ```
   - Нажми **Развернуть** -> **Новое развертывание** -> выбери тип **Веб-приложение**.
   - Доступ укажи: *"Все"* (*Anyone*).
   - Скопируй полученный **URL веб-приложения**.

4. **Установи Webhook:**
   - Выполни HTTP-запрос в браузере для привязки вебхука к Telegram:
     ```http
     [https://api.telegram.org/bot](https://api.telegram.org/bot)<ТВОЙ_ТОКЕН_БОТА>/setWebhook?url=<URL_ВЕБ_ПРИЛОЖЕНИЯ>
     ```
